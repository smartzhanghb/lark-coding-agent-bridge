# 会话工作区与运行可靠性

版本：0.8.0-workspaces.1。基于原项目 0.7.1 增量改造，保持原有 Agent、模型、飞书身份、附件和业务工具接入。

## 启用与操作

在对应 profile 的 `workspaces` 中设置 `managedBindings: true`，保留原 `default`。此开关默认关闭，旧安装升级不会未经管理员决定就改变已有聊天的行为；本次本机部署显式开启。

本机控制台进入 profile 后，“项目与会话”提供项目添加、改名、停用、删除和聊天绑定。工作目录必须是具体、可访问的目录，不能使用磁盘根、Home 根或其他过宽目录。项目改名保留 ID；已有绑定时不能直接改变项目路径。

- `/ws current`：当前聊天项目和运行状态。`/status` 同样显示当前项目卡片。
- `/ws list`：所有者私聊展示项目和切换按钮；群聊只显示当前项目。
- `/ws bind 项目名` 或 `/ws use 项目名`：所有者绑定当前聊天，默认新会话。
- `/ws bind 项目名 --stop`：明确停止当前聊天及子话题的运行、取消排队后切换。
- `/ws unbind [--stop]`：解除绑定并暂停聊天任务；话题解绑阻止继续继承群目录。
- `/ws inherit [--stop]`：话题恢复继承群绑定。
- `/cd 绝对路径`：所有者注册目录并绑定当前聊天；运行繁忙时先 `/stop`。
- `/ws save 名称`：把当前工作目录注册为项目；`/ws remove 名称` 仅删除无绑定的项目，绝不删除文件目录。
- `/new`：新会话，保留项目绑定。`/new chat` 的目录继承仅所有者可操作。
- `/resume`：仅所有者显式选择本聊天、同 Agent、同真实目录、同权限策略的历史；不读取整个本机目录的其他会话历史。
- `/stop`：停止当前聊天运行、取消目录等待／进程池等待以及后续排队消息。

群中命令仍遵守现有 @ 规则。新私聊先向机器人发消息才会登记到控制台；群列表来自机器人可见群和接收到的消息。私聊名称取消息发送者可见名称，缺少名称时显示 ID。无需新增个人 OAuth 权限。

未绑定的同事聊天不启动 Agent；所有者个人私聊可使用原默认目录。显式解绑后即便所有者也不回退到默认目录。目录失效或项目停用都停止执行，不改派目录。

## 数据、权限与一致性

工作区存储升级为 v2，保留旧 `chats`、`named`，新增 `projects`、`bindings`、`conversations`、`epochs`。首次迁移先保存 `workspaces.json.pre-v2`；历史 cwd 仅展示为待核对目录，不自动授权聊天。

管理写操作通过 profile 当前运行进程完成，离线不允许另起写入者。页面 API 仍仅监听回环地址，要求本机令牌并检查请求来源。飞书侧 owner-only 规则覆盖目录命令、建群继承及卡片回调。修改绑定带修订号，陈旧页面／卡片会拒绝；成功回复必须等待原子落盘，失败保留旧数据。

绑定只负责路由，Agent 沿用现有完整工具权限，不提供操作系统级文件／凭据隔离。受信同事共享同一群的上下文；不同群、私聊、话题不会因目录相同而共享上下文。首批不引入每个人的独立系统身份。

切换与 `/new` 递增会话代次；迟到消息、旧 system 事件和旧恢复候选不能写回新会话。会话 catalog 的权限指纹包含代次，避免 A→B→A 自动接回 A 的旧会话。恢复采用当前代次的新活动记录，旧历史仍可保留。

## 调度与维护

受管 IM 任务按真实目录串行；注册路径存在父子重叠时也冲突，不同目录可并行，总并发沿用 profile 配置。目录锁在此 supervisor 进程内共享，不约束其他编辑器、终端、独立部署实例或旧版非受管运行入口。目录等待、进程池等待都可取消；启动前重新校验目录、绑定版本、权限及策略时效。未确认子进程退出时保留运行槽，避免并行覆盖。

当前实现保留已有云文档评论／会议入口及其运行规则，首批会话绑定面向群聊、私聊、话题；这些其他入口不宣称受聊天绑定控制。

保留 WebSocket 15 秒存活窗口和原空闲超时设置。工具调用期间是否暂停空闲计时沿用原项目行为；没有强制总时长杀进程。停用本机旧“总时长超 5 分钟 kill -9” watchdog。

`ops/weekly-restart.mjs` 通过已认证的本机控制台请求空闲重连：有运行、排队或绑定变更时跳过本次维护；空闲时关闭新接收窗口，复核后重连。连接前后在同一 supervisor 内切换，不使用 pgrep/kill。异常退出不自动重放用户任务，避免重复文件修改或外部业务操作。

## 验收与回退

开发检查包括完整原回归、工作区集成测试、目录调度测试、HTTP 身份校验、前后端类型检查、页面构建和 CLI 打包。真实群聊／私聊的消息、卡片和模型输出需要在机器人切换后单独验收；本地模拟通过不能代替真实消息证明。

升级前备份配置、会话、工作区、已安装包和 LaunchAgent，并保存校验清单。回退时先停止新版本，再还原配置／会话／工作区与原 LaunchAgent 和 CLI 符号链接；不要让旧版与新版同时写状态。
